## 📝 Лабораторна робота №6: Робота з кодом у Bundler Vite

### Опис

Застосунок "Менеджер Нотаток" демонструє роботу з Vite, модульну архітектуру та використання сторонніх бібліотек.

### Технології

- **Vite** - сучасний збиральник та dev-сервер
- **JavaScript (ES6+)** - модульна система
- **Day.js** - робота з датами
- **CSS3** - стилізація з підтримкою темної/світлої теми

### Структура проєкту

```
lab6-vite-project/
├── src/
│   ├── main.js       # Точка входу
│   ├── data.js       # Бізнес-логіка для роботи з даними
│   ├── ui.js         # Управління DOM та інтерфейсом
│   ├── utils.js      # Допоміжні функції (з Day.js)
│   └── style.css     # Стилі
├── vite.config.js    # Конфігурація Vite
├── index.html
└── package.json
```

### Функціональність

- ✅ Додавання нових нотаток
- ✅ Видалення нотаток з підтвердженням
- ✅ Форматування дат за допомогою Day.js
- ✅ Автоматичне оновлення (HMR)
- ✅ Адаптивний дизайн
- ✅ Підтримка темної/світлої теми

### Встановлення та запуск

```bash
cd lab6-vite-project

# Встановити залежності
npm install

# Запустити dev-сервер (http://localhost:3000)
npm run dev

# Зібрати для продакшену
npm run build

# Переглянути зібраний проєкт
npm run preview
```

### Особливості реалізації

1. **Модульна архітектура**: Код розділено на окремі модулі відповідно до принципу єдиної відповідальності
2. **Інкапсуляція**: Прямий доступ до масиву даних обмежено, тільки через функції API
3. **Day.js**: Використовується для форматування дат з українською локалізацією
4. **Vite конфігурація**: Налаштовано псевдоніми для імпортів та порт dev-сервера

## 🌐 Лабораторна робота №7: Використання HTTP-запитів

### Опис

Веб-застосунок "Менеджер Завдань" демонструє роботу з HTTP-запитами, RESTful API, пагінацією та кешуванням.

### Технології

- **Fetch API** - для HTTP-запитів
- **JSONPlaceholder** - публічне API для тестування
- **ES6 Modules** - модульна архітектура
- **LocalStorage** - збереження стану
- **CSS3** - сучасний адаптивний дизайн

### Структура проєкту

```
task-manager/
├── src/
│   ├── main.js       # Ініціалізація застосунку
│   ├── api.js        # HTTP-запити та робота з API
│   └── ui.js         # Управління DOM та рендеринг
├── index.html        # HTML структура
└── styles.css        # Стилі
```

### Функціональність

- ✅ Отримання завдань з пагінацією (GET)
- ✅ Створення нових завдань (POST)
- ✅ Оновлення завдань (PATCH)
- ✅ Видалення завдань (DELETE)
- ✅ Групове оновлення завдань
- ✅ Кешування запитів
- ✅ Збереження стану в LocalStorage
- ✅ Обробка помилок
- ✅ Адаптивний інтерфейс

### Встановлення та запуск

```bash
cd task-manager

# Запуск через Live Server (якщо встановлено)
# або відкрийте index.html в браузері

# Для продакшену можна використати будь-який статичний сервер
npx serve .
```

### API Endpoints

Використовується JSONPlaceholder API:

```
GET    /todos?_page=1&_limit=10  # Отримати завдання
POST   /todos                     # Створити завдання
PATCH  /todos/:id                 # Оновити завдання
DELETE /todos/:id                 # Видалити завдання
```

### Особливості реалізації

#### 1. Модуль api.js

- **checkResponse()** - перевірка статусу відповіді
- **getTasks()** - отримання завдань з кешуванням
- **createTask()** - створення нового завдання
- **updateTask()** - часткове оновлення (PATCH)
- **deleteTask()** - видалення завдання
- **bulkUpdate()** - групове оновлення через Promise.all()

#### 2. Кешування

```javascript
// Кеш реалізовано через Map
const cache = new Map();

// Ключ кешу формується з параметрів запиту
const cacheKey = `tasks_${page}_${limit}`;
```

#### 3. Обробка помилок

```javascript
try {
  const response = await fetch(url);
  checkResponse(response);
  const data = await response.json();
  // обробка даних
} catch (error) {
  console.error('Помилка:', error);
  showNotification(`Помилка: ${error.message}`, 'error');
}
```

#### 4. Пагінація

- Кнопки "Назад" / "Вперед"
- Відображення поточної сторінки
- Збереження сторінки в LocalStorage

### Приклад запиту

```javascript
// Створення завдання
const newTask = await createTask({
  title: 'Нове завдання',
  completed: false,
  userId: 1
});

// Оновлення завдання
const updated = await updateTask(5, {
  completed: true
});
```

## 🎯 Контрольні запитання

### Лабораторна №6

1. **Що таке Vite?** - Сучасний інструмент збірки, що складається з dev-сервера (з HMR) та команди збірки
2. **Pre-bundling** - Попередня обробка залежностей для оптимізації
3. **HMR** - Hot Module Replacement - технологія миттєвого оновлення модулів без перезавантаження сторінки
4. **Створення проєкту Vite**: `npm create vite@latest` → обрати шаблон → `npm install` → `npm run dev`

### Лабораторна №7

1. **Стартовий рядок HTTP**: метод + URL + версія протоколу
2. **HTTP методи**:
   - GET - отримання даних
   - POST - створення ресурсу
   - PUT - повна заміна ресурсу
   - PATCH - часткове оновлення
   - DELETE - видалення ресурсу
3. **Код 201** - Created (ресурс створено)
4. **401 vs 403**: 401 = не автентифікований, 403 = автентифікований, але немає прав
5. **Promise.all()** - виконує кілька промісів паралельно і повертає масив результатів
