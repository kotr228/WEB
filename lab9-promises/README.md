# Лабораторна робота №9: Обробка промісів та промісіфікація

Практичне вивчення роботи з промісами (Promises) у JavaScript та техніки промісіфікації callback-функцій.

## Опис проєкту

Цей проєкт створено як частину лабораторної роботи №9 "Обробка промісів. Промісіфікація на практиці". Він демонструє:
- Використання `Promise.all()` для паралельного виконання асинхронних операцій
- Ланцюжки промісів (`.then().then().catch().finally()`)
- Промісіфікацію callback-функцій (ручна та через `util.promisify()`)
- Обробку помилок в асинхронному коді
- Комбінатори промісів (`Promise.all()`, `Promise.allSettled()`)

## Теоретична частина

### Проміси (Promises)

**Проміс** — об'єкт, що представляє результат асинхронної операції у майбутньому.

**Три стани промісу:**
1. **pending** (очікування) — початковий стан
2. **fulfilled** (виконано) — операція завершена успішно
3. **rejected** (відхилено) — операція завершена з помилкою

**Створення промісу:**
```javascript
const promise = new Promise((resolve, reject) => {
  // Асинхронна операція
  if (/* успіх */) {
    resolve(value);
  } else {
    reject(error);
  }
});
```

### Методи промісів

#### then()
Приймає callback для обробки успішного результату:
```javascript
promise.then(
  value => { /* успіх */ },
  error => { /* помилка */ }
);
```

#### catch()
Обробляє тільки помилки (скорочення для `then(null, onRejected)`):
```javascript
promise.catch(error => {
  console.error('Помилка:', error);
});
```

#### finally()
Виконується завжди після завершення (успіх чи помилка):
```javascript
promise.finally(() => {
  console.log('Завершено');
});
```

### Комбінатори промісів

#### Promise.all(iterable)
Виконується коли **всі** проміси виконані. Відхиляється при **першій** помилці.
```javascript
Promise.all([promise1, promise2, promise3])
  .then(([result1, result2, result3]) => { /* всі виконані */ })
  .catch(error => { /* хоча б один відхилено */ });
```

#### Promise.allSettled(iterable)
Чекає завершення **всіх** промісів незалежно від результату:
```javascript
Promise.allSettled([promise1, promise2])
  .then(results => {
    results.forEach(result => {
      if (result.status === 'fulfilled') {
        console.log('Значення:', result.value);
      } else {
        console.log('Помилка:', result.reason);
      }
    });
  });
```

#### Promise.race(iterable)
Повертає результат **першого** завершеного промісу:
```javascript
Promise.race([promise1, promise2])
  .then(result => { /* перший виконаний */ });
```

#### Promise.any(iterable)
Виконується при **першому** успішному промісі:
```javascript
Promise.any([promise1, promise2])
  .then(result => { /* перший успішний */ })
  .catch(errors => { /* всі відхилено */ });
```

### Промісіфікація

**Промісіфікація** — перетворення callback-функції в promise-функцію.

**Ручна промісіфікація:**
```javascript
function delayPromise(ms) {
  return new Promise(resolve => {
    setTimeout(resolve, ms);
  });
}
```

**Через util.promisify():**
```javascript
import { promisify } from 'util';

const delayPromise = promisify(delay);
```

**Для функцій з кількома результатами:**
```javascript
function promisifyMulti(fn) {
  return function(...args) {
    return new Promise((resolve, reject) => {
      fn(...args, (err, ...results) => {
        if (err) reject(err);
        else resolve(results);
      });
    });
  };
}
```

## Контрольні запитання

1. **Що таке проміс та які у нього стани?**
   - Об'єкт для асинхронних операцій: pending, fulfilled, rejected

2. **Яка різниця між then() та catch()?**
   - `then()` обробляє успіх та помилки, `catch()` тільки помилки

3. **Для чого використовується finally()?**
   - Виконується завжди після завершення, для фіналізації ресурсів

4. **Різниця між Promise.all() та Promise.allSettled()?**
   - `all()` — відхиляється при першій помилці
   - `allSettled()` — чекає всіх незалежно від результату

5. **Що таке промісіфікація?**
   - Перетворення callback-функції в promise-функцію

6. **Як працює util.promisify()?**
   - Автоматично створює promise-обгортку для callback-функцій

7. **Коли використовувати Promise.all()?**
   - Для паралельного виконання незалежних асинхронних операцій

8. **Як обробляти помилки в ланцюжку промісів?**
   - Через `.catch()` в кінці ланцюжка або в кожному `.then()`

9. **Різниця між async/await та промісами?**
   - async/await — синтаксичний цукор над промісами, більш читабельний

10. **Коли краще використовувати Promise.race()?**
    - Для таймаутів або вибору найшвидшого запиту
